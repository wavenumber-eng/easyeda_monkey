# EasyEDA Monkey 2026.9.11

`2026.9.11` expands supported Python versions from 3.12 to 3.12 through 3.14.
This allows downstream consumers, including Altium Cruncher, to use Python 3.14
without overriding the package's interpreter requirement.

CI covers Python 3.12, 3.13, and 3.14 on Windows, Linux, and macOS. Release
validation and publishing use Python 3.14. Parser behavior, CLI arguments, and
downloaded component bundle formats are unchanged.

The build uses Hatchling 1.31.0 to keep generated package metadata compatible
with the release validator.
