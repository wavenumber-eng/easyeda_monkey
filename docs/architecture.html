Architecture

EasyEDA Monkey is a parser and download support package. It preserves EasyEDA-native symbols, footprints, SVG path fragments, pads, holes, vias, tracks, and 3D model references for downstream tooling.

Layers

  • easyeda_api: LCSC/EasyEDA component API client.
  • easyeda_* modules: typed parser/data model boundaries.
  • cli.py: top-level CLI orchestration only.
  • cli_commands/: one module per public command.
  • docs/contracts/: command, interface, and exception manifests.

Boundaries

Conversion policy for KiCad, Altium, or other EDA formats is intentionally outside this package. Public behavior must be backed by Rack tests and design documentation before release.
